ICS 2102: WEB DEVELOPMENT
SEMESTER MINI PROJECT
Student Club Website
Project Question
You have been tasked with designing and developing a website for a student club or society of your choice. The website should provide information about the club, its activities and events, and allow interested students to submit their details to join or contact the club.
The website must be developed progressively throughout the semester, applying the concepts covered in ICS 2102: Web Development, including web design principles, HTML, CSS, JavaScript, arrays, objects, events, forms and PHP.
Requirements
Your website should contain at least five interconnected pages, including:
1.	Home Page – Introduce the club and provide navigation to the other pages.
2.	About Us – Provide information about the club, including its objectives, vision, mission and committee members.
3.	Activities/Events – Display the club’s activities and upcoming events.
4.	Gallery – Display images related to the club and its activities.
5.	Join/Contact Us – Provide a form through which students can submit their details to join or contact the club.
Technical Requirements
Your project should demonstrate the following:
A. HTML
•	Use appropriate HTML tags and attributes.
•	Include headings, paragraphs, links, images, lists, tables and forms.
•	Create appropriate navigation between pages.
B. CSS
•	Use CSS to improve the appearance and layout of the website.
•	Demonstrate the box model, positioning, backgrounds and navigation styling.
•	Use an external CSS file where appropriate.
C. JavaScript
•	Validate the Join/Contact form.
•	Use variables, operators and conditional statements.
•	Use loops and functions where appropriate.
•	Include at least one interactive feature.
D. Arrays, Objects and Events
•	Use an array to store or display information such as club activities or events.
•	Demonstrate at least one JavaScript event such as onclick, onload, mouseover or mouseout.
•	Use an appropriate JavaScript object where applicable.
E. PHP
•	Use PHP to process the Join/Contact form.
•	Display an appropriate response after the form has been submitted.
•	Where database connectivity has been covered, store and retrieve submitted information from a database.


F. HOSTING AND DEPLOYMENT

•	You are required to deploy your completed website on a web hosting platform of your choice. 
•	The website must be publicly accessible through a working URL. 
•	You should submit the website URL. 
•	The choice of hosting provider is at your discretion, provided that the selected platform supports the technologies used in the project.
Each student must submit:
1.	 The URL of the working website.
Important
The project should demonstrate the concepts taught in ICS 2102. Students are expected to build the website progressively as the different topics are covered during the semester. The focus is on functionality, correct application of web development concepts, good design and creativity, rather than developing a complex system.
Marks: 100
